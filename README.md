The GPS's one-line excuse for sending the driver down the wrong road: I didn't take a wrong turn, I took a shortcut — the map just forgot the lake, the wedding, and that your car can't swim. The program in `main.ts` writes that single line (120 characters) to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
